## Hangisini kullanmalı?

- Sunum veya ilk anlatım: **Şema A** (sade hat)
- ÇED, ISO, proses tarifnamesi: **Şema B** + **Versiyon 3** resmi paragraf
- Fitting imalatı: **Şema C**
- İlk kez okuyan biri: **Versiyon 2**
