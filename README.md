# GES Metraj Pro

Yerel çalışan bir GES (Güneş Enerji Santrali) malzeme miktarı hesaplama aracı.

Bu uygulama bağımsızdır; başka bir projeye bağlı değildir.

## Kurulum

```bash
npm install
```

## Yerel çalıştırma

```bash
npm run dev
```

## Test

```bash
npm test
```

## Üretim derlemesi

```bash
npm run build
```
