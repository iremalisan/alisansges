# Tesis Yerleşim Planı

Orijinal tarama görselinden vektörel olarak yeniden çizilmiş tesis yerleşim planı.

## Dosyalar

- `tesis-yerlesim-plani.drawio` — diagrams.net / draw.io dosyası (kutular ayrı ayrı düzenlenebilir)
- `tesis-yerlesim-plani.pdf` — aynı planın PDF çıktısı

## draw.io dosyasını açma

1. [https://app.diagrams.net](https://app.diagrams.net) adresini açın
2. **Open Existing Diagram** → **Device** ile `.drawio` dosyasını seçin

Masaüstü Draw.io uygulamasında **File → Open** yeterlidir.

Lejant:

- Mavi nokta: Atıksu
- Sarı nokta: Emisyon
